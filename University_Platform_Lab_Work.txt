ЗЕРТХАНАЛЫҚ ЖҰМЫС
УНИВЕРСИТЕТТІҢ ОНЛАЙН ОҚУ ПЛАТФОРМАСЫ
Дерекқор схемасын жобалау, SQL, Neon PostgreSQL, Sequelize ORM және Node.js REST API

Мақсаты:
Университеттің онлайн оқу платформасына арналған дерекқор құру, кестелер арасындағы байланыстарды ұйымдастыру, SQL сұраныстарын орындау және Node.js көмегімен REST API әзірлеу.

ҚОЛДАНЫЛАТЫН ТЕХНОЛОГИЯЛАР
- PostgreSQL және Neon — дерекқор.
- SQL — деректермен жұмыс істеу тілі.
- Sequelize — ORM кітапханасы.
- Node.js — серверлік орта.
- Express — REST API құруға арналған фреймворк.
- Postman — API сұраныстарын тексеру құралы.

2. ER-ДИАГРАММА ЖӘНЕ ДЕРЕКҚОР СХЕМАСЫ
============================================================

Жобада бес кесте қолданылады:
1) departments — кафедралар;
2) teachers — оқытушылар;
3) students — студенттер;
4) subjects — пәндер;
5) registrations — студенттердің пәндерге тіркелуі.

Байланыстар:
- Бір кафедрада бірнеше оқытушы болуы мүмкін (1:N).
- Бір оқытушы бірнеше пән жүргізе алады (1:N).
- Студент пен пән арасындағы байланыс көптен көпке (M:N).
  Бұл байланыс registrations кестесі арқылы жасалады.
- registrations кестесінде student_id және subject_id құрама
  бастапқы кілт болады. Бұл бір студенттің бір пәнге қайталап
  тіркелуіне жол бермейді.

DROP TABLE IF EXISTS registrations CASCADE;
DROP TABLE IF EXISTS subjects CASCADE;
DROP TABLE IF EXISTS students CASCADE;
DROP TABLE IF EXISTS teachers CASCADE;
DROP TABLE IF EXISTS departments CASCADE;

CREATE TABLE departments (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL UNIQUE,
    building VARCHAR(50) NOT NULL
);

CREATE TABLE teachers (
    id SERIAL PRIMARY KEY,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    department_id INTEGER NOT NULL,
    FOREIGN KEY (department_id)
        REFERENCES departments(id)
);

CREATE TABLE students (
    id SERIAL PRIMARY KEY,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    group_name VARCHAR(30) NOT NULL
);

CREATE TABLE subjects (
    id SERIAL PRIMARY KEY,
    title VARCHAR(100) NOT NULL,
    description TEXT,
    credits INTEGER NOT NULL CHECK (credits > 0),
    teacher_id INTEGER NOT NULL,
    FOREIGN KEY (teacher_id)
        REFERENCES teachers(id)
);

CREATE TABLE registrations (
    student_id INTEGER NOT NULL,
    subject_id INTEGER NOT NULL,
    registered_at DATE NOT NULL DEFAULT CURRENT_DATE,
    grade INTEGER CHECK (grade BETWEEN 0 AND 100),
    PRIMARY KEY (student_id, subject_id),
    FOREIGN KEY (student_id)
        REFERENCES students(id) ON DELETE CASCADE,
    FOREIGN KEY (subject_id)
        REFERENCES subjects(id) ON DELETE CASCADE
);

ФАЙЛ: sql/queries.sql

-- 1. Барлық студенттер
SELECT * FROM students;

-- 2. Пәндер және оларды жүргізетін оқытушылар
SELECT s.title, t.full_name
FROM subjects AS s
JOIN teachers AS t ON s.teacher_id = t.id;

-- 3. Студенттер, пәндер және бағалар
SELECT st.full_name, su.title, r.grade
FROM registrations AS r
JOIN students AS st ON r.student_id = st.id
JOIN subjects AS su ON r.subject_id = su.id;

-- 4. Әр пәнге тіркелген студенттер саны
SELECT su.title, COUNT(r.student_id) AS student_count
FROM subjects AS su
LEFT JOIN registrations AS r ON su.id = r.subject_id
GROUP BY su.id, su.title;

-- 5. Үш немесе одан көп студенті бар пәндер
SELECT su.title, COUNT(r.student_id) AS total
FROM subjects AS su
JOIN registrations AS r ON su.id = r.subject_id
GROUP BY su.id, su.title
HAVING COUNT(r.student_id) >= 3;

-- 6. Орташа бағадан жоғары бағалар
SELECT *
FROM registrations
WHERE grade > (SELECT AVG(grade) FROM registrations);

-- 7. Пән кредитін өзгерту
UPDATE subjects SET credits = 6 WHERE id = 1;

-- 8. Тіркелуді жою
DELETE FROM registrations
WHERE student_id = 4 AND subject_id = 3;

-- 9. Транзакция
BEGIN;
UPDATE registrations
SET grade = 95
WHERE student_id = 1 AND subject_id = 1;
COMMIT;

-- 10. Индекс құру
CREATE INDEX idx_registrations_subject
ON registrations(subject_id);

-- 11. Сұраныс жоспарын талдау
EXPLAIN ANALYZE
SELECT * FROM registrations WHERE subject_id = 1;

Ескерту: UPDATE және DELETE мысалдары деректерді өзгертеді.
Оларды тест дерекқорында орындаған дұрыс. Индексті қайта
құрмас бұрын қажет болса мына команданы орындауға болады:
DROP INDEX IF EXISTS idx_registrations_subject;

4. ҮШІНШІ ҚАЛЫПТЫ ФОРМА (3ҚФ)
============================================================

Дерекқор схемасы қалыпты формалар талаптарын сақтай отырып
жобаланған.

1ҚФ — барлық өрістер атомарлы мәндерден тұрады. Мысалы,
студенттің аты-жөні, электрондық поштасы және тобы бөлек
бағандарда сақталады.

2ҚФ — кілттік емес атрибуттар бастапқы кілтке толық тәуелді.
registrations кестесіндегі registered_at және grade атрибуттары
құрама кілттің екі бөлігіне де тәуелді.

3ҚФ — кілттік емес атрибуттар басқа кілттік емес атрибуттарға
тәуелді емес. Мысалы, оқытушының аты-жөні мен электрондық
поштасы subjects кестесінде қайталанбайды, тек teacher_id
сыртқы кілті сақталады.

Осы құрылым мәліметтердің қайталануын азайтады және жаңарту,
қосу, жою кезіндегі аномалиялардың алдын алуға көмектеседі.

6. SEQUELIZE ҚОСЫЛЫМЫ — src/db.js
============================================================

require('dotenv').config();

const { Sequelize, DataTypes } = require('sequelize');

const sequelize = new Sequelize(process.env.DATABASE_URL, {
    dialect: 'postgres',
    logging: false,
    dialectOptions: {
        ssl: {
            require: true,
            rejectUnauthorized: false
        }
    }
});

const Department = sequelize.define('Department', {
    name: {
        type: DataTypes.STRING,
        allowNull: false,
        unique: true
    },
    building: {
        type: DataTypes.STRING,
        allowNull: false
    }
}, {
    tableName: 'departments',
    timestamps: false
});

const Teacher = sequelize.define('Teacher', {
    fullName: {
        type: DataTypes.STRING,
        field: 'full_name',
        allowNull: false
    },
    email: {
        type: DataTypes.STRING,
        unique: true,
        allowNull: false
    },
    departmentId: {
        type: DataTypes.INTEGER,
        field: 'department_id',
        allowNull: false
    }
}, {
    tableName: 'teachers',
    timestamps: false
});

const Student = sequelize.define('Student', {
    fullName: {
        type: DataTypes.STRING,
        field: 'full_name',
        allowNull: false
    },
    email: {
        type: DataTypes.STRING,
        unique: true,
        allowNull: false
    },
    groupName: {
        type: DataTypes.STRING,
        field: 'group_name',
        allowNull: false
    }
}, {
    tableName: 'students',
    timestamps: false
});

const Subject = sequelize.define('Subject', {
    title: {
        type: DataTypes.STRING,
        allowNull: false
    },
    description: DataTypes.TEXT,
    credits: {
        type: DataTypes.INTEGER,
        allowNull: false,
        validate: { min: 1 }
    },
    teacherId: {
        type: DataTypes.INTEGER,
        field: 'teacher_id',
        allowNull: false
    }
}, {
    tableName: 'subjects',
    timestamps: false
});

const Registration = sequelize.define('Registration', {
    studentId: {
        type: DataTypes.INTEGER,
        primaryKey: true,
        field: 'student_id',
        allowNull: false
    },
    subjectId: {
        type: DataTypes.INTEGER,
        primaryKey: true,
        field: 'subject_id',
        allowNull: false
    },
    registeredAt: {
        type: DataTypes.DATEONLY,
        field: 'registered_at',
        allowNull: false,
        defaultValue: DataTypes.NOW
    },
    grade: {
        type: DataTypes.INTEGER,
        allowNull: true,
        validate: { min: 0, max: 100 }
    }
}, {
    tableName: 'registrations',
    timestamps: false
});

Department.hasMany(Teacher, { foreignKey: 'departmentId' });
Teacher.belongsTo(Department, { foreignKey: 'departmentId' });

Teacher.hasMany(Subject, { foreignKey: 'teacherId' });
Subject.belongsTo(Teacher, { foreignKey: 'teacherId' });

Student.belongsToMany(Subject, {
    through: Registration,
    foreignKey: 'studentId',
    otherKey: 'subjectId'
});

Subject.belongsToMany(Student, {
    through: Registration,
    foreignKey: 'subjectId',
    otherKey: 'studentId'
});

Student.hasMany(Registration, { foreignKey: 'studentId' });
Registration.belongsTo(Student, { foreignKey: 'studentId' });

Subject.hasMany(Registration, { foreignKey: 'subjectId' });
Registration.belongsTo(Subject, { foreignKey: 'subjectId' });

module.exports = {
    sequelize,
    Department,
    Teacher,
    Student,
    Subject,
    Registration
};

require('dotenv').config();

const express = require('express');
const {
    sequelize,
    Student,
    Teacher,
    Subject,
    Registration
} = require('./db');

const app = express();
app.use(express.json());

const PORT = process.env.PORT || 3000;

// Негізгі бет
app.get('/', (req, res) => {
    res.json({
        message: 'University Platform API',
        status: 'Server is working'
    });
});

// Барлық пәндер
app.get('/subjects', async (req, res) => {
    try {
        const subjects = await Subject.findAll({
            include: [{ model: Teacher }]
        });
        res.status(200).json(subjects);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Бір пән
app.get('/subjects/:id', async (req, res) => {
    try {
        const id = Number(req.params.id);
        if (!Number.isInteger(id) || id < 1) {
            return res.status(400).json({ error: 'ID дұрыс емес' });
        }

        const subject = await Subject.findByPk(id, {
            include: [{ model: Teacher }]
        });

        if (!subject) {
            return res.status(404).json({ error: 'Пән табылмады' });
        }
        res.status(200).json(subject);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Жаңа пән қосу
app.post('/subjects', async (req, res) => {
    try {
        const { title, description, credits, teacherId } = req.body;
        const errors = [];

        if (typeof title !== 'string' || !title.trim()) {
            errors.push('Пән атауы бос болмауы керек');
        }
        if (!Number.isInteger(credits) || credits < 1) {
            errors.push('Кредит саны 0-ден үлкен бүтін сан болуы керек');
        }
        if (!Number.isInteger(teacherId) || teacherId < 1) {
            errors.push('Оқытушы ID дұрыс емес');
        }
        if (errors.length) {
            return res.status(400).json({ errors });
        }

        const teacher = await Teacher.findByPk(teacherId);
        if (!teacher) {
            return res.status(404).json({ error: 'Оқытушы табылмады' });
        }

        const subject = await Subject.create({
            title: title.trim(),
            description,
            credits,
            teacherId
        });
        res.status(201).json(subject);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Пәнді өзгерту
app.put('/subjects/:id', async (req, res) => {
    try {
        const id = Number(req.params.id);
        if (!Number.isInteger(id) || id < 1) {
            return res.status(400).json({ error: 'ID дұрыс емес' });
        }

        const subject = await Subject.findByPk(id);
        if (!subject) {
            return res.status(404).json({ error: 'Пән табылмады' });
        }

        const { title, description, credits, teacherId } = req.body;

        if (title !== undefined &&
            (typeof title !== 'string' || !title.trim())) {
            return res.status(400).json({ error: 'Пән атауы дұрыс емес' });
        }
        if (credits !== undefined &&
            (!Number.isInteger(credits) || credits < 1)) {
            return res.status(400).json({ error: 'Кредит саны дұрыс емес' });
        }
        if (teacherId !== undefined) {
            if (!Number.isInteger(teacherId) || teacherId < 1) {
                return res.status(400).json({ error: 'Оқытушы ID дұрыс емес' });
            }
            const teacher = await Teacher.findByPk(teacherId);
            if (!teacher) {
                return res.status(404).json({ error: 'Оқытушы табылмады' });
            }
        }

        await subject.update({
            title: title === undefined ? subject.title : title.trim(),
            description: description === undefined ? subject.description : description,
            credits: credits === undefined ? subject.credits : credits,
            teacherId: teacherId === undefined ? subject.teacherId : teacherId
        });

        res.status(200).json(subject);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Пәнді жою
app.delete('/subjects/:id', async (req, res) => {
    try {
        const id = Number(req.params.id);
        if (!Number.isInteger(id) || id < 1) {
            return res.status(400).json({ error: 'ID дұрыс емес' });
        }

        const subject = await Subject.findByPk(id);
        if (!subject) {
            return res.status(404).json({ error: 'Пән табылмады' });
        }

        await subject.destroy();
        res.status(200).json({
            message: 'Пән сәтті жойылды',
            id
        });
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Студентті пәнге тіркеу
app.post('/registrations', async (req, res) => {
    try {
        const { studentId, subjectId, grade } = req.body;

        if (!Number.isInteger(studentId) || studentId < 1 ||
            !Number.isInteger(subjectId) || subjectId < 1) {
            return res.status(400).json({
                error: 'Студент немесе пән ID дұрыс емес'
            });
        }

        if (grade !== undefined && grade !== null &&
            (!Number.isInteger(grade) || grade < 0 || grade > 100)) {
            return res.status(400).json({
                error: 'Баға 0 мен 100 арасында болуы керек'
            });
        }

        const student = await Student.findByPk(studentId);
        const subject = await Subject.findByPk(subjectId);

        if (!student || !subject) {
            return res.status(404).json({
                error: 'Студент немесе пән табылмады'
            });
        }

        const existing = await Registration.findOne({
            where: { studentId, subjectId }
        });

        if (existing) {
            return res.status(409).json({
                error: 'Студент бұл пәнге бұрын тіркелген'
            });
        }

        const registration = await Registration.create({
            studentId,
            subjectId,
            grade: grade === undefined ? null : grade
        });

        res.status(201).json(registration);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Студенттің пәндері, бағалары және оқытушылары
app.get('/students/:id/subjects', async (req, res) => {
    try {
        const id = Number(req.params.id);
        if (!Number.isInteger(id) || id < 1) {
            return res.status(400).json({ error: 'ID дұрыс емес' });
        }

        const student = await Student.findByPk(id, {
            include: [{
                model: Registration,
                include: [{
                    model: Subject,
                    include: [{ model: Teacher }]
                }]
            }]
        });

        if (!student) {
            return res.status(404).json({ error: 'Студент табылмады' });
        }

        res.status(200).json(student);
    } catch (error) {
        res.status(500).json({ error: error.message });
    }
});

// Серверді іске қосу
async function startServer() {
    try {
        await sequelize.authenticate();
        console.log('PostgreSQL қосылды!');

        app.listen(PORT, () => {
            console.log(`Сервер іске қосылды: http://localhost:${PORT}`);
        });
    } catch (error) {
        console.error('Қосылу қатесі:', error.message);
        process.exitCode = 1;
    }
}

startServer();

9. REST API ЭНДПОИНТТЕРІ ЖӘНЕ POSTMAN МЫСАЛДАРЫ
============================================================

HTTP әдістері мен жолдары:

GET     /subjects                 — барлық пәндерді көру
GET     /subjects/:id             — бір пәнді көру
POST    /subjects                 — жаңа пән қосу
PUT     /subjects/:id             — пәнді өзгерту
DELETE  /subjects/:id             — пәнді жою
POST    /registrations            — студентті пәнге тіркеу
GET     /students/:id/subjects    — студенттің пәндерін көру

HTTP жауап кодтары:
200 — сұраныс сәтті орындалды.
201 — жаңа жазба құрылды.
400 — енгізілген мәлімет қате.
404 — сұралған жазба табылмады.
409 — қайталанған тіркелу.
500 — сервер қатесі.

POSTMAN СҰРАНЫСТАРЫ

1) Барлық пәндерді алу:
GET http://localhost:3000/subjects

2) Жаңа пән қосу:
POST http://localhost:3000/subjects

Body → raw → JSON:
{
  "title": "Мобильді бағдарламалау",
  "description": "Android және Kotlin",
  "credits": 5,
  "teacherId": 1
}

3) Пәнді өзгерту:
PUT http://localhost:3000/subjects/1

Body:
{
  "credits": 6
}

4) Студентті пәнге тіркеу:
POST http://localhost:3000/registrations

Body:
{
  "studentId": 1,
  "subjectId": 3,
  "grade": 95
}

5) Студенттің пәндерін көру:
GET http://localhost:3000/students/1/subjects

6) Пәнді жою:
DELETE http://localhost:3000/subjects/1

Postman-да JSON жібергенде Body бөлімінде raw және JSON
түрін таңдаңыз.

10. ИНДЕКС ЖӘНЕ EXPLAIN ANALYZE
============================================================

Индекс дерекқордан қажетті жазбаларды іздеуді жылдамдатуға
көмектеседі. registrations кестесінің құрама бастапқы кілті
student_id бағанынан басталады. Сондықтан subject_id бойынша
жиі іздеу үшін жеке индекс құру пайдалы болуы мүмкін.

Индекске дейін сұраныс жоспарын тексеру:

EXPLAIN ANALYZE
SELECT * FROM registrations
WHERE subject_id = 1;

Индекс құру:

CREATE INDEX idx_registrations_subject
ON registrations(subject_id);

Индекстен кейін қайта тексеру:

EXPLAIN ANALYZE
SELECT * FROM registrations
WHERE subject_id = 1;

Кесте көлемі аз болса, PostgreSQL Seq Scan таңдауы мүмкін.
Үлкен кестеде индекс арқылы іздеу тиімді болуы ықтимал.
Нақты уақыт пен жоспар деректер көлеміне және Neon ортасына
байланысты өзгереді.

12. ҚОРЫТЫНДЫ
============================================================

Бұл зертханалық жұмыста университеттің онлайн оқу платформасына
арналған дерекқор жүйесі жобаланды. PostgreSQL көмегімен
кафедралар, оқытушылар, студенттер, пәндер және тіркелулер
кестелері құрылды.

Кестелер арасында сыртқы кілттер арқылы байланыстар орнатылып,
үшінші қалыпты форма талаптары қарастырылды. SQL тілінің
SELECT, JOIN, GROUP BY, UPDATE және DELETE командалары қолданылды.

Сонымен қатар Neon платформасы арқылы бұлттық дерекқор құрылып,
Sequelize ORM көмегімен Node.js қосымшасына қосылды. Express
арқылы REST API жасалып, пәндерді қосу, көру, өзгерту және жою,
студентті пәнге тіркеу функциялары орындалды.

Зертханалық жұмыс нәтижесінде дерекқорды жобалау, SQL
сұраныстарын орындау, ORM технологиясын пайдалану және
серверлік қосымша құру бойынша тәжірибелік дағдылар қалыптасты.
